# Portfolio client

Frontend React construit avec Vite.

## Développement

Le backend doit tourner sur le port `3000`. Vite transmet automatiquement les
requêtes `/api`, `/og-image` et `/sitemap.xml` vers celui-ci.

```bash
npm install
npm run dev
```

L'application est alors disponible sur `http://localhost:5173`.

## Commandes

```bash
npm run dev      # serveur de développement Vite
npm run build    # build de production dans client/build
npm run preview  # prévisualisation du build Vite
npm run lint     # analyse ESLint
```
